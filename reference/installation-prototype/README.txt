클래스온 학생 확장 · 설치 진단용 개발 빌드

현재 학생 등록 서버는 연결되어 있지 않습니다. 설치 완료와 학생 등록 완료는 다릅니다.
실제 학생 정보를 입력하거나 실제 수업에 배포하지 마세요.

1. 내 파일에 새 개발용 폴더를 만들고 ZIP의 모든 파일을 압축 해제하거나 복사합니다.
2. chrome://extensions에서 개발자 모드를 켭니다(학교 정책이 허용하는 기기).
3. 압축해제된 확장 프로그램을 로드합니다를 누르고 manifest.json이 있는 폴더를 선택합니다.
4. 자동으로 열리는 설치 확인 창에서 대상 학급과 진단 메시지를 확인합니다.
5. 설치한 폴더는 삭제하지 마세요. 업데이트는 같은 폴더의 파일을 교체하고 확장을 새로고침합니다.

이 개발 버전은 사이트 수집·기기 제어를 하지 않으며 실제 등록·잠금·공지·캡처·도움 요청은 미구현입니다.
고정 교사 암호, 예전 Apps Script 주소, 인증키를 포함하지 않습니다.
