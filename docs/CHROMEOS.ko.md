# 실제 크롬북 검증표 — 아직 실행하지 않음

아래 표는 학교 테스트 담당자가 실제로 확인할 항목이다. Node/Vitest·PostgreSQL/PGlite·데스크톱 Chromium 테스트의 통과를 아래 항목 통과로 대신하지 않는다. 최소 Chrome 120 이상이 필요하다.

| ---- | ------------------------------------- | ------------------------------------------------------------------------------------- |
| 1    | 코드/SQL/함수/Google OAuth/Pages 설정 | 본인 UUID만 대시보드 접근, 다른 계정 차단                                             |
| 2    | 공통 ZIP 수동 설치                    | 개발자 모드 허용 기기에서 설치, 다른 학급도 같은 ZIP 사용                             |
| 3    | 코드 만료·중복 번호·승인 전 등록      | 잘못된 신청 거부, 승인 전에는 학생 데이터/명령 수신 불가                              |

| 7    | 개별·전체 잠금과 문구                 | 검은 Chrome 팝업과 정확한 문구, 요청을 ACK 전에 성공 표시하지 않음                    |

기록할 것: 날짜·ChromeOS/Chrome 버전·기기 모델·학교 정책·네트워크 환경·코드 버전·대상 수·각 단계 결과. 학생 식별 정보·토큰·캡처 원본은 공개 저장소의 테스트 보고서에 넣지 않는다.

현재 코드가 실제 계정·학교 기기에서 이 표를 통과했다는 보고는 없다.

추가 보안 업데이트 실기기 검증:

- ZIP 1.1을 적용하고 공지가 별도의 확장 창에 표시되는지 확인합니다. 일반 웹사이트·Chrome 보호 페이지·잠금 창 상태에서 표시/닫기/기한을 확인합니다. 웹페이지 안에 공지 원문이 삽입되면 구형 확장을 사용 중인 것입니다.
- 구형 확장은 최신 서버에서 보안 업데이트 오류를 표시하고 새로운 교사 명령을 받지 않아야 합니다. 기존 잠금은 lease로 안전 해제되는지 확인합니다.
- 시크릿 모드에서 확장 사용을 허용한 기기에서도 시크릿 탭을 기록·캡처하지 않는지 확인합니다.
- 정상 캡처의 uploaded=true·applied, 실패/중단 캡처의 비공개 예약과 정리, 서버 갱신 후 다른 계정 거부를 확인합니다.

- ZIP 1.2에서 카메라·파일·설정 앱을 열고 실제 주소가 감지되는 기기인지 확인합니다. 감지되지 않는 앱을 웹사이트처럼 임의 생성하지 않아야 합니다. 카메라 앱 활동 기록과 카메라 촬영 영상 캡처는 별개이며 후자는 제공하지 않습니다.
