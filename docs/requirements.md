# 기존 기능 유지와 웹 전환 요구사항

## 우선순위와 현재 범위

기존 Apps Script 프로그램의 주요 기능을 유지하면서 반응 속도·안정성·교사 조작 편의성을 개선한다. 기능 삭제나 설치 없는 웹 참여 방식으로의 축소는 하지 않는다. 학생 연결은 **교사 웹에서 ZIP 제공 → 학생 압축 해제 → 개발자 모드에서 확장 불러오기 → 학급·학생 등록** 방식으로 유지한다. 개발용 ZIP 생성과 설치 진단 확장만 구현했다. 실제 등록·기기 기능은 미연동이다.

기존 원본 3개를 참고 자료로 분석했다. [분석과 새 설계](legacy-review.md)에 v2.0 ZIP과 v5.3 생성기의 차이, 유지할 동작, 새 구조를 정리했다. 코드 구조를 복제하지 않으며 실제 기능 동등성은 후속 ChromeOS 검증 대상이다.

| 유지 대상               | 현재 웹 구현                                  | 실제 연동에서 필요한 작업                  |
| ----------------------- | --------------------------------------------- | ------------------------------------------ |
| 현재 사이트             | 학급 ON일 때 가상 사이트 표시                 | 확장 탭 이벤트, 허용된 URL 수집, 서버 갱신 |

## 학급 관리

정규 학급·동아리·외부 수업을 생성한다. 기본 학급 약 20명, 전체 99명까지 가상 데이터로 검증한다. 빈 학급도 허용하며 중복 이름과 잘못된 인원은 거부한다. 새 학급은 OFF로 시작한다.

학급 ID와 학생 ID로 목록·기록·오류·명령 결과를 분리한다. 전환 시 검색·선택만 초기화하고 다른 학급의 ON/OFF나 학생 상태는 변경하지 않는다. 학급 이름·유형·학생 수·ON/OFF만 브라우저 로컬 저장소에 보관한다. 실행 중 잠금·문구·공지·도움 요청·기록·오류는 저장하지 않고 새로고침 시 가상 초기값으로 돌아간다. 서버 동기화나 다른 기기 공유는 아니다.

ON/OFF는 현재 로컬 가상 기록 설정이다. 기존 프로그램과 같이 OFF는 기록만 일시 중지하며 마지막 가상 상태를 표시한다. 잠금·해제·공지·캡처와 학생 연결은 별도다. 기록을 중지했다고 기존 잠금을 임의 해제하거나 대기 중 제어를 취소하지 않는다. 다른 학급 설정도 유지한다. 후속 서버에서는 이 설정을 학급별로 검증하고 사이트/체류 이력 쓰기를 중지하되 제어·안전 복구·연결 상태 경로는 유지한다.

## 오류와 복구

- 해당 학생 카드에만 짧은 오류 배지를 표시한다. 클릭하면 작업 종류, 오류 코드, 원인, 해결 방법을 본다. 서로 다른 작업의 오류를 한 번의 성공으로 모두 지우지 않는다.
- 오프라인 학생은 전체 작업에서 제외하며 그 학생 카드에 이유를 표시한다. 연결이 없는 학생에게 오래된 잠금·공지를 무기한 예약하지 않는다.
- 가상 전송 어댑터는 명시적인 일시 통신 오류만 500ms/1000ms 간격으로 최대 2회 재시도한다. 학생별 대기 상태를 표시하고 다른 학생의 작업은 계속 처리한다. 최종 실패는 오류로 남긴다.
- 같은 학생의 중복 실행을 막으며 전체 해제는 대기 중 잠금보다 우선한다. 요청 취소·컴포넌트 종료 시 재시도를 중단하고, 늦은 응답으로 다시 잠기지 않도록 한다.
- 가상 잠금은 1/5/10분 만료를 선택하며 자동 해제한다. 실제 기기 복구가 보장된다는 뜻은 아니다.
- 실제 Realtime 재연결·heartbeat·DB 재동기화는 미구현이다. 전송 재시도만으로 실제 기기가 재연결되었다고 표시하지 않는다. 후속 구현 시 지수 백오프·jitter, 구독 정리, 재연결 후 스냅샷 재조회, 명령 ID별 중복 방지와 만료를 검증한다.
- 권한·캡처 API 미연동 등 영구 오류는 자동 반복하지 않는다. 브라우저 설정 저장 실패는 학생 문제가 아니므로 학급 설정 안내에 표시한다.

개발 검증용 학생 요약의 접힌 영역에서 도움 요청, 일시 통신 오류 1회, 연결 종료·재연결을 가상으로 발생시킬 수 있다. 실제 이벤트나 학생 대상 기능으로 오인하지 않도록 별도로 표시한다.

## 실제 ChromeOS에서 별도 검증할 항목

| 항목               | 확인 기준                                                                                 |
| ------------------ | ----------------------------------------------------------------------------------------- |
| ZIP 설치·기기 등록 | 관리 기기의 개발자 모드 허용 여부, 실제 기존 ZIP 설치 절차, 중복·만료·폐기 등록           |
| 사이트·체류시간    | 활성 탭 전환, 유휴, 창 여러 개, 절전·재부팅·서비스 워커 종료, 지원하지 않는 Chrome 페이지 |
| 잠금·문구·해제     | 실제 적용 범위, 전체/개별 해제, 자동 만료, 오프라인·재시작 후 긴급 복구, 늦은 잠금 차단   |
| 공지·도움 요청     | 실제 수신·표시·교사 확인 응답, 중복 방지, 재연결·학급 전환 중 올바른 대상                 |
| 화면 캡처          | 기존 방식과 실제 Chrome 권한·정책, 캡처 가능 범위, 거부·실패 처리, 저장 권한·보존         |
| 학급 모니터링      | 학급별 ON/OFF의 서버·확장 반영, OFF 시 실제 기록 중단·제어 유지, 다른 학급 격리           |
| 안정성             | 교사 간 RLS 격리, 계정 만료, 네트워크 단절·복구, 99명 미만 실제 동시 연결 부하            |

일반 데스크톱 Chromium UI 테스트를 위 ChromeOS 검증의 대체 증거로 사용하지 않는다. 기존 기능을 불가능하다고 임의 삭제하지 않고 실제 구현·정책을 확인하여 검증 결과와 남은 제약을 명시한다.
