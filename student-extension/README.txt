클래스온 학생 확장 1.2 / 보안 프로토콜 2
1. 모든 파일을 새 폴더에 압축 해제합니다. 폴더는 설치 후에도 유지하세요.
2. chrome://extensions에서 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다 → manifest.json이 있는 폴더를 선택합니다.
3. 교사의 참여 코드, 학생 번호, 이름을 입력하고 등록 신청합니다.
4. 교사가 대시보드에서 승인한 뒤 연결됩니다. 설치만으로 승인되지는 않습니다.
5. 확장 아이콘에서 도움을 요청하거나 연결 오류를 확인할 수 있습니다.
학교 정책이 허용한 Chrome 기능만 사용합니다. OS 전체 잠금을 보장하지 않습니다.
잠금 기한 만료·통신 두절(최대 120초의 로컬 lease)에는 안전 해제합니다.
교사 비상 코드는 교사가 발급한 뒤 이 기기가 정상 동기화한 경우 오프라인에서도 사용 가능합니다.
알람·창·Chrome 자체 종료나 OS 절전의 시간 정확성은 ChromeOS에서 별도 검증하세요.
학교 테스트 전 기존 운영 확장을 제거하지 마세요. 두 확장이 동시에 제어하지 않게 테스트 기기를 분리하세요.

공지는 웹페이지에 삽입하지 않고 확장 전용 창으로 표시하며 시크릿 탭은 수집·캡처하지 않습니다.
보안 업데이트에는 새 ZIP·서버 함수·④ SQL이 모두 필요합니다. 이전 확장은 최신 서버에서 거부됩니다.

Chrome API가 노출하는 일부 내부 앱 주소(카메라·파일·설정)는 고정된 앱 이름으로 기록합니다. Android·Linux·ChromeOS 전체 앱 실행을 열거하거나 카메라 촬영 영상을 수집하는 기능은 아닙니다. 실제 감지 여부는 기기에서 확인해야 합니다.
