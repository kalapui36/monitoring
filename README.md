1\. 개요<br>
&nbsp;&nbsp;&nbsp;가. 시스템명: 크롬북 모니터링 및 화면 제어 시스템(Google Sheets 기반)<br>
&nbsp;&nbsp;&nbsp;나. 목적: 구글 앱스 스크립트를 활용한 학급 크롬북 화면 실시간 모니터링 및 제어<br>
&nbsp;&nbsp;&nbsp;다. 작동 방식: 학생 기기에 전용 확장 프로그램(크롬 학습 도우미) 설치 및 구글 스프레드시트 연동<br>
<br>
2\. 주요 기능<br>
&nbsp;&nbsp;&nbsp;가. 실시간 모니터링: 학생의 현재 접속 사이트, 접속 주소(URL), 체류 시간(분/초) 실시간 기록<br>
&nbsp;&nbsp;&nbsp;나. 화면 제어(잠금): 특정 학생의 크롬북 화면 즉시 차단 및 사용자 지정 메시지 전송<br>
&nbsp;&nbsp;&nbsp;다. 화면 캡처: 학생 화면 캡처 후 교사의 구글 드라이브 자동 저장 및 시트 내 연결 주소(링크) 생성<br>
&nbsp;&nbsp;&nbsp;라. 과부하 방지: 시트 과부하 방지를 위한 전체 기록 수집 켜기/끄기(ON/OFF) 기능 제공<br>
&nbsp;&nbsp;&nbsp;마. 로그 관리: 학생별 개별 탭 자동 생성 및 클릭 1회로 모든 로그 초기화 지원<br>
<br>
3\. 교사 시스템 설정 순서<br>
&nbsp;&nbsp;&nbsp;가. 빈 구글 스프레드시트를 생성하고 메뉴에서 [확장 프로그램] - [Apps Script] 실행<br>
&nbsp;&nbsp;&nbsp;나. 코드 파일(Code.gs, installDialog.html)을 동일한 이름으로 생성하고 제공된 코드 입력<br>
&nbsp;&nbsp;&nbsp;다. 우측 상단의 [배포] - [새 배포] 클릭<br>
&nbsp;&nbsp;&nbsp;라. 배포 유형은 [웹 앱]으로 선택하고, 액세스 권한은 반드시 [모든 사용자(Anyone)]로 설정 후 배포<br>
&nbsp;&nbsp;&nbsp;마. 구글 스프레드시트 화면으로 돌아와 새로고침(F5) 실행<br>
&nbsp;&nbsp;&nbsp;바. 상단에 생성된 [시스템 관리] - [학생용 설치 파일 생성] 메뉴 클릭<br>
&nbsp;&nbsp;&nbsp;사. 다운로드된 파일(Chrome_Edu_Extension.zip)을 학생에게 배포하여 크롬 브라우저(개발자 모드)에 등록<br>
<br>
4\. 참고 및 유의 사항<br>
&nbsp;&nbsp;&nbsp;가. 명단 등록: 원활한 작동을 위해 대시보드 시트의 A열(번호), B열(이름), C열(이메일)에 명단을 미리 입력할 것을 권장함.<br>
&nbsp;&nbsp;&nbsp;나. 비상 해제 기능: 학생 기기 잠금 화면에서 단축키(Alt+Shift+K) 입력 시 암호 프롬프트가 생성되며, 해제 암호(4021) 입력 시 잠금 해제됨.
